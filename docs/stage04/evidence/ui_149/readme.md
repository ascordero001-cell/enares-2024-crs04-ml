# Capturas de revisión visual #149

Estas dos capturas de viewport 1536 × 864 se generaron con el entrypoint canónico
`app/streamlit_app.py` en modo local autorizado y con el mismo agregado V0 que ya
existe en el repositorio. No son capturas de la URL privada Cloud Run ni una
publicación institucional. Se incluyen para comparar composición, tamaños de
columnas, seis tarjetas y tipografía tras el ajuste pedido el 2026-10-01.

- `resumen-1536x864.png`: apertura del módulo 3.1.
- `tema-3-2-1-1536x864.png`: tema 3.2.1 con filtros en Nacional.

El script `npm run test:ui-parity` genera además los originales completos en
`artifacts/ui-parity/` (no versionados) y comprueba los 26 nombres departamentales
en el SVG del gráfico. Ninguna captura contiene microdatos, credenciales ni rutas
locales. V0 continúa siendo el release oficial; Cloud Run sigue privado.
